# OmniVerse — PS5 Comics & Gaming Hub

> **Neo-Comic Cyber-Console Storefront**: Uniting serialized digital graphic novels, manga, and PlayStation 5 next-generation hardware and games.

Built entirely with **HTML5, Vanilla CSS, and JavaScript**.

---

## ⚡ Highlights & Features

- **Kinetic Obsidian Design System**:
  - Curated high-contrast palette: PlayStation Electric Cobalt (`#0070D1`), Kinetic Neon Crimson (`#FF1756`), Comic Action Amber (`#FFB800`), and Abyssal Obsidian (`#080B14`).
  - Modern typography powered by **Space Grotesk** & **Plus Jakarta Sans**.
  - Halftone dot textures, emissive laser borders, and angled comic-panel geometry.

- **Console Dock Cart Drawer**:
  - Slide-out cyber cart with live quantity controls, subtotal calculations, and free armored shipping progress tracker ($150 threshold).
  - Promo voucher support (e.g., `OMNI15` for 15% VIP discount).
  - Simulated instant PSN direct key dispatch checkout animation.

- **Interactive Comic Reader Modal**:
  - Flip through multi-page previews with pagination controls, page counter, and panel zoom.

- **Live Telemetry Search**:
  - Real-time catalog autocomplete search with thumbnail previews and auto-scroll highlighting.

- **Format Rocker Switcher**:
  - Toggle between **Digital Code** (0.0s PSN sync) and **Disc Case** (factory sealed + lithograph) across all PS5 titles.

- **Interactive Community Poll**:
  - Real-time voting with animated telemetry percentage bars and +100 OmniVerse points reward.

- **Synthesizer Web Audio FX**:
  - High-tech cybernetic UI clicks and chimes generated directly via the Web Audio API with an on/off audio toggle in the navbar.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or serve it locally:

```bash
# Using Python
python3 -m http.server 8080

# Or using Node
npx serve .
```

Visit: `http://localhost:8080/index.html`
